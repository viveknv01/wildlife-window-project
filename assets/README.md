# Assets

The current prototype draws its forest and simplified animal shapes procedurally using Canvas. It does not require bundled image or audio files.

`assets/icons/favicon.png` is the forest-window mark for the browser tab and the installable page (192×192 PNG, kept small for mobile).

When adding assets later:

- Prefer original, commissioned, public-domain, or clearly licensed material.
- Record the asset name, creator/source, URL, license, and any attribution requirement.
- Do not commit assets with unclear usage rights.
- Keep assets optimized for mobile bandwidth.
- Consider graceful fallbacks if optional audio or visual assets fail to load.

# Contributing

## Before starting

Read `AGENTS.md` and the relevant product/technical documents in `docs/`.

## Workflow

1. Identify one focused improvement.
2. Describe the intended player-facing behaviour.
3. Make the smallest maintainable change.
4. Test desktop and mobile layouts.
5. Check browser console errors.
6. Update the documentation if behaviour, scope, or implementation changes.

## Code style

- Prefer readable vanilla JavaScript.
- Use descriptive names.
- Keep rendering, input handling, and game data understandable.
- Avoid unnecessary abstractions for a small prototype.
- Do not add dependencies for functionality that can be implemented simply with browser APIs.

## Assets

Any added image, sound, font, or other asset must have a documented source and usage license in `assets/README.md`.

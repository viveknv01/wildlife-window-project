# Project Overview

## One-sentence concept

A player relaxes inside a house near a jungle, looks through a window, notices wildlife appearing in the forest, and captures moments as personal screenshots.

## Product identity

- Genre: casual observation / wildlife photography / relaxing game
- Platform: browser-based web game, responsive on desktop and mobile
- Visual direction: 2D illustrated scene
- Mood: peaceful, curious, slow-paced
- Session style: short visits are enjoyable; there is no pressure to stay online
- Persistence: none in the prototype; no player records are saved

## Target experience

The player should feel like they are quietly observing a real place. The forest should not feel like a menu or a level-selection screen. The window is the main interface and the jungle is the main content.

## Current scope

The first prototype intentionally includes only:
- One jungle scene
- One window/view
- Morning/daytime mood
- 10–15 animal and bird types
- Random animal appearances
- Simple movement
- Zoom
- Screenshot capture
- Basic rarity

## Out of scope for the first prototype

- Multiple locations or windows
- Night mode and seasons
- Weather simulation
- Torch and night vision
- Binocular-specific mechanics
- Animal soundscape and alarm calls
- Complex animal AI or predator/prey simulation
- Player accounts, records, achievements, cloud saves, and leaderboards
- Admin panel or server-controlled rarity

# Roadmap

The roadmap is staged. Do not implement later-stage ideas unless the project owner asks for them.

## Stage 1 — Playable prototype (current)

- [x] One jungle environment
- [x] One window/view
- [x] Morning/daytime atmosphere
- [x] 10–15 animal/bird entries
- [x] Random appearances
- [x] Basic movement
- [x] Zoom
- [x] PNG screenshot download
- [x] Basic rarity weights
- [x] Responsive browser layout
- [x] Improve natural-looking animal silhouettes and movement
- [ ] Add gentle background ambience (only with properly licensed/original audio)
- [ ] Test on real mobile browsers and fix issues

## Stage 2 — Better observation

- [x] More convincing animal movement and idle behaviours
- [x] Different movement styles per species
- [x] Better depth/occlusion so animals can hide behind foliage
- [ ] Optional animal sound cues
- [x] Better capture feedback and camera framing
- [ ] Improve performance on lower-end phones

## Stage 3 — Environment variation

- [ ] Day-to-evening transition
- [ ] Night scene
- [ ] Weather variation
- [ ] Seasonal variation
- [ ] Torch/night-vision mechanics

## Stage 4 — Deeper wildlife behaviour

- [x] Idle activities (grazing, drinking, sitting, resting) and walk-in/walk-out entrances without fades
- [x] Prey flee when a predator appears
- [ ] Animal awareness and disturbance reactions (beyond predator flight)
- [ ] Alarm calls
- [ ] Species-specific habitat and time preferences
- [x] Group sightings and animal interactions
- [x] Carefully designed rare encounter events

## Explicitly not planned yet

- Player accounts or saved progress
- Persistent photo album inside the game
- Leaderboards or competitive scoring
- Admin panel or cloud-controlled animal spawn settings
- Multiple habitats

Revisit these only if the product owner changes the scope.
